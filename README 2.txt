LINEUPS10 SPORTS WORLDS

Files:
- index.html  : entrance page
- fifa.html   : FIFA World
- nhl.html    : NHL World
- nba.html    : NBA World
- worlds.css  : shared styling
- worlds.js   : search, filters, sorting, video cards

How to use:
1. Put all files in the same website folder.
2. Open index.html.
3. Optional: place your existing videos.json in the same folder.
   The script will try to load and categorise those videos automatically.
   If videos.json is missing, the included sample cards are displayed.

New:
- Shorts and Long Form filters are included in FIFA, NHL, and NBA worlds.
- Videos are classified automatically using duration and Shorts-related title/tags.
